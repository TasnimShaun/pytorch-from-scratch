# NumPy and PyTorch

Practiced converting between NumPy arrays and PyTorch tensors.

## Tensor -> NumPy

```python
b = a.numpy()
```

## NumPy -> Tensor

```python
d = torch.from_numpy(c)
```

## AI/ML connection

NumPy is widely used for numerical computing and preprocessing, while PyTorch tensors are used for neural network computation and GPU acceleration. Being able to move between them is useful in practical ML workflows.
