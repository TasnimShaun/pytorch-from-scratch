# PyTorch From Scratch 🚀

A structured learning repository for understanding **PyTorch and Deep Learning from the fundamentals**.

This repository is built around a simple learning workflow:

> **Concept → Mathematics → From-Scratch Implementation → PyTorch Implementation → Experiment → Practical Use**

The current section focuses on **Tensor Fundamentals**, based directly on my learning notebook.

## 🧠 Learning Philosophy

For every major concept, I want to understand:

### 1. Concept

**What is it?**

### 2. Why

**Why do we need it?**

### 3. Mathematics

**What mathematical operation is happening?**

### 4. Implementation

**How can I implement it myself?**

### 5. PyTorch

**How does PyTorch provide it?**

### 6. Experiment

**What happens when I change the input, shape, dtype, or device?**

### 7. Practical Use

**Where is it used in real AI/ML systems?**
