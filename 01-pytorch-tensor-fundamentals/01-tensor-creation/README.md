# Tensor Creation

## Concept

A **Tensor** is PyTorch's main data structure for storing and computing with numerical data.

## What I practiced

- `torch.empty()`
- `torch.zeros()`
- `torch.ones()`
- `torch.rand()`
- `torch.manual_seed()`
- `torch.tensor()`
- `torch.arange()`
- `torch.linspace()`
- `torch.eye()`
- `torch.full()`

## Key idea

Different constructors are useful for creating tensors with different initial values or patterns.

## Reproducibility

`torch.manual_seed(100)` was used to demonstrate that the same seed produces the same random sequence.

## AI/ML connection

Tensors are the basic data structure used for:

- model inputs
- weights and biases
- activations
- gradients
- images and batches
