# Tensor Operations

This section covers the mathematical and logical operations practiced in the original notebook.

## Scalar Operations

- addition
- subtraction
- multiplication
- division
- integer division
- modulo
- power

## Element-wise Operations

Operations applied independently to corresponding tensor elements.

- `+`
- `-`
- `*`
- `/`
- `**`
- `%`
- `torch.abs`
- `torch.neg`
- `torch.round`
- `torch.ceil`
- `torch.floor`
- `torch.clamp`

## Reduction Operations

Used to reduce tensor values into summaries.

- `sum`
- `mean`
- `median`
- `max`
- `min`
- `prod`
- `std`
- `var`
- `argmax`
- `argmin`

The examples also demonstrate `dim=0` and `dim=1`.

## Matrix Operations

- matrix multiplication with `torch.matmul`
- dot product with `torch.dot`
- transpose
- determinant
- inverse

## Comparison Operations

- `>`
- `<`
- `==`
- `!=`
- `>=`
- `<=`

## Special Functions

- `log`
- `exp`
- `sqrt`
- `sigmoid`
- `softmax`
- `relu`

## AI/ML connection

These operations appear everywhere in deep learning: linear algebra, loss calculation, normalization, activations, and model forward passes.
