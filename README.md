# PyTorch From Scratch 🚀

A structured journey to learn **PyTorch** from the fundamentals to advanced deep learning and research-level concepts.

This repository contains my **notes, implementations, experiments, and projects** while learning PyTorch and Deep Learning.

The goal is not only to learn how to use PyTorch, but to understand **what happens under the hood** — from tensors and automatic differentiation to neural networks, CNNs, Transformers, distributed training, and deployment.

---

## 🎯 Goals

* Learn PyTorch from **zero to advanced level**
* Understand the fundamentals behind Deep Learning
* Implement important concepts **from scratch**
* Reproduce concepts using **PyTorch**
* Build practical Deep Learning projects
* Experiment with different architectures and techniques
* Develop a strong foundation for **AI/ML research**

```text

   ↓
```
